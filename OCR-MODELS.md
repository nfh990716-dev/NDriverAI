# OCR language data

The `ara.traineddata` and `eng.traineddata` files are Tesseract LSTM language models, included locally so first-run OCR does not need to download model files. Upstream language data and documentation: https://github.com/tesseract-ocr/tessdata_fast and https://github.com/tesseract-ocr/tessdoc/blob/main/Data-Files.md. Tesseract language model files are provided under Apache 2.0 terms as documented upstream.
